# Artefak Drizzle

Folder ini berisi hasil Drizzle lama dan hanya digunakan sebagai referensi schema.
Jangan gunakan untuk migration production At Cell. Sumber migration canonical
ada di `supabase/migrations/`; jalankan seluruh berkas di sana berurutan, atau
pakai `supabase/RUN-ALL-PENDING.sql` untuk project yang benar-benar kosong.
Daftar lengkap dan urutannya ada di `docs/DEPLOYMENT-REDUNDANCY.md`.
